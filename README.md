## Project Description

The Personal Task Manager is a Laravel-based web application that allows users to manage their personal tasks. Users can add, view, edit, delete, and update the status of their tasks.

The project demonstrates the basic Laravel flow:

**Routes → Controller → Model → Database → Blade**

## Database

The system uses MySQL as its database.

The `tasks` table contains:

* `id`
* `task_name`
* `description`
* `status`
* `due_date`
* `created_at`
* `updated_at`
